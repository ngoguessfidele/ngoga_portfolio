# Ngoga Portfolio - Modern Developer Portfolio

A sleek, professional portfolio website built with Next.js 13+, showcasing full-stack development skills through featured projects, technical expertise, and modern web development practices. This portfolio demonstrates advanced React development, responsive design, and effective project presentation.

## 🌟 Project Overview

Ngoga Portfolio is a comprehensive developer portfolio that highlights technical skills, project experience, and professional achievements. Built with modern web technologies, it features a clean design, smooth animations, and optimized performance to create an impressive first impression for potential employers and clients.

## 🚀 Features

- **Responsive Design**: Fully responsive layout that works seamlessly across all devices
- **Dark Mode Support**: Automatic dark/light mode with system preference detection
- **Project Showcase**: Interactive project gallery with filtering and detailed views
- **Skills Presentation**: Visual representation of technical skills and expertise
- **Contact Integration**: Functional contact form with validation
- **Performance Optimized**: Fast loading with Next.js optimizations and image optimization
- **SEO Friendly**: Proper meta tags, structured data, and search engine optimization
- **Accessibility**: WCAG compliant with proper ARIA labels and keyboard navigation

## 🛠️ Technology Stack

- **Framework**: Next.js 13+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Custom SVG icons and Lucide React
- **Forms**: React Hook Form with validation
- **Animations**: CSS transitions and Tailwind animations
- **Deployment**: Vercel (optimized for Next.js)

## 📁 Project Structure


## 🔧 Installation & Setup

```bash
# Clone the repository
git clone <your-repo-url>
cd ngoga_portfolio

# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000 in your browser
```

## 📱 Available Scripts

```bash

# Production

npm run start        # Start production server
```
